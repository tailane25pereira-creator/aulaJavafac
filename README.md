# 📐 Cálculo de Cerâmica em Java

Aplicação desenvolvida em **Java** para calcular a quantidade necessária de peças de cerâmica/piso para cobrir a área de um determinado terreno ou cómodo.

## 🚀 Sobre o Projeto
O algoritmo solicita ao utilizador as dimensões da peça de cerâmica (largura e comprimento) e as dimensões do terreno, calculando automaticamente a área total e o número exato de peças necessárias para a obra.

## 🛠️ Tecnologias e Conceitos Utilizados
* **Java** (JDK)
* **Classe `Scanner`** (`java.util.Scanner` para entrada de dados via consola)
* **Estrutura de Variáveis e Operadores Matemáticos**
* **Lógica de Programação e Algoritmos**

## 💻 Como Executar

2. Clona o repositório ou transfere o ficheiro `CalculoCeramica.java`.
3. Compila e executa o código no terminal/IDE:
   ```bash
